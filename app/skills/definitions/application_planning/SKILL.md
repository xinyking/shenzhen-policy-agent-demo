# application_planning

只在用户明确要求添加日程、计划或提醒时安排；不因普通政策问答自动创建事项或提交政务申请。
事项内容围绕标题、个人计划日期、材料清单和备注；办理方法可以合并进备注，不要求用户再次完整编辑。
个人计划日期和官方申报截止日期分开。没有明确计划日期时只补问日期，不用文件发布日期代替计划日期，也不猜截止日。
材料只使用本轮原文明示内容及可追溯引用；未明确的材料保持为空或注明待核查，不能把资格要求变成材料。
添加日程不表示已提交政策申请，不保证获得资格或补贴；当前没有自动提醒能力，不能声称一定会推送提醒。
仍遵守调用节点已有JSON字段契约；不新增未授权工具，不绕过后端校验，不从本技能生成政策事实。
